# Анализ тональности комментариев
Интернет-магазин запускает новый сервис. Теперь пользователи могут редактировать и дополнять описания товаров. То есть клиенты предлагают свои правки и комментируют изменения других. Магазину нужен инструмент, который будет искать токсичные комментарии и отправлять их на модерацию. 

Необходимо обучить модель классифицировать комментарии на позитивные и негативные. В распоряжении набор данных с разметкой о токсичности правок.

Значение метрики качества *F1* не меньше 0.75. 

**Ход выполнения проекта**

1. Загружены и подготовлены данные.
2. Обучены разные модели. 
3. Сделаны выводы и даны рекомендации

**Результат проведенного исследования**: В работе было разработано решение, позволяющее интернет-магазину классифицировать комментраии на позитивные и негативные. Выбранная модель удовлетворяет требованиям заказчика (метрика *F1* на тестовой выборке ниже 0.75). Качество модели LogisticRegression на тестовой выборке (*F1*) составляет 0.79, при этом модель отличается высокой скоростью обучения модели и предсказаний.
